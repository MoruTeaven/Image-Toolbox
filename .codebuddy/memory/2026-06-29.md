## 修复移动/框选工具属性面板只读问题

**问题**：切换到移动/框选工具后，属性面板中选中图层的 X/Y/宽/高/旋转等参数显示为 `disabled` 只读状态，用户无法直接通过输入框修改。

**根因**：其他工具（如打码、裁剪）激活时，`BaseModule.activate()` 调用 `_disableObjectsInteractivity()` 将所有对象的 `selectable`/`evented` 设为 `false`。切换到 SelectModule 时，虽然 `canvas.selection = true` 恢复框选，但对象的 `selectable`/`evented` 未恢复 → `LayerManager._createMeta` 判定 `locked = !selectable && !evented = true` → `PropertyPanel._getLayerPropertiesHTML` 检查到 `locked = true` 设置 `editDisabled = ' disabled'` → 输入框只读。

**修复**：`SelectModule.activate()` 中添加 `this._restoreObjectsInteractivity()` 调用，恢复所有对象的交互性。

**涉及文件**：
- `core/src/modules/SelectModule.js`（源文件）
- `dist/uTools/core/src/modules/SelectModule.js`
- `dist/zTools/core/src/modules/SelectModule.js`

**更新日志**：`updateRecords.js`（源 + 两个 dist 副本）的 2.2.2 版本 fixed 列表中新增条目："修复切换移动/框选工具后，属性面板位置/大小/旋转等参数显示为只读无法直接编辑的问题"

## BaseModule 工具停用锁定图层错误解锁修复

**问题**：`_restoreObjectsInteractivity()` 在第79行存在兜底 fallback：对不在 `_savedInteractivity` 映射中的对象盲设为 `selectable: true, evented: true`。当工具激活期间有新对象加入画布时（如覆盖层、裁剪遮罩等），这些对象的锁定状态被破坏——原本被用户锁定的图层或被动的背景图层会被错误解锁。

**根因**：`_restoreObjectsInteractivity` 中 `else { obj.set({ selectable: true, evented: true }) }` 分支对所有未知对象强制执行解锁。

**修复**：移除 `else` 分支，只恢复已保存在 `_savedInteractivity` 中的对象状态；不在映射中的对象保持原样不做修改。

**涉及文件**：
- `core/src/modules/BaseModule.js`（源）
- `dist/uTools/core/src/modules/BaseModule.js`
- `dist/zTools/core/src/modules/BaseModule.js`
- `core/src/updateRecords.js`（源 + 两份 dist）— v2.3 fixed 列表新增条目
- `AGENTS.md` — 新增记录

## HistoryManager 撤销/重做异步恢复状态日志补录

**问题分析**：用户报告 `undo()`/`redo()` 未等待 `fromJSON` 异步完成就重置 `_isRestoring`，导致画布恢复期间 `object:added` 等事件错误触发 `saveState()` 写入重复/损坏快照。

**排查结果**：检查三个副本（`core/src`、`dist/uTools`、`dist/zTools`）的 `HistoryManager.js`，发现 `undo()`/`redo()` 已经是 `async` 方法，已正确 `await this._restoreState()` → `_cm.fromJSON()`，`_isRestoring` 在 `finally` 块中于 `await` 完成后才重置。`CanvasManager.fromJSON()` 返回的 Promise 仅在 `loadFromJSON` 回调（含 `enlivenObjects` 恢复 clipPath）完成后才 resolve。恢复期间 `_isRestoring` 始终为 `true`，`saveState()` 会提前返回。代码修复已就位。

**本次操作**：仅将此修复补录到 v2.3 更新日志 `fixed` 列表（源 + 两份 dist），未改动 `HistoryManager.js` 代码。

**涉及文件**：
- `core/src/updateRecords.js`
- `dist/uTools/core/src/updateRecords.js`
- `dist/zTools/core/src/updateRecords.js`
