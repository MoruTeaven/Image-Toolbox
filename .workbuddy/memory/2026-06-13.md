## 修复橡皮擦多次擦除问题（最终修复）
- **问题**：橡皮擦工具多次擦除时，之前的擦除效果会随机变化位置
- **尝试过的方案**：
  1. 用 `fabric.Group` 合并路径 → Group 创建时会重新计算中心点和子对象相对坐标，导致漂移
  2. 使用 `absolutePositioned: true` → 仍会触发 Fabric.js 内部布局计算
  3. 像素级擦除方案 → 异步回调导致对象引用问题
- **最终方案**：
  - 使用 `absolutePositioned: false`（相对坐标）+ 坐标系转换
  - `_createEraseClipPath` 中使用 `fabric.util.invertTransform` 和 `applyTransformToObject` 将画布绝对坐标转换为目标对象的局部坐标系
  - 采用嵌套 clipPath 链表结构：`newErasePath.clipPath = oldClip`
  - 每个擦除路径在目标对象自己的坐标系中，不受后续操作影响
- **涉及文件**：`EraserModule.js`
