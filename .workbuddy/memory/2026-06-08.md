## Bug 修复
- **死循环修复**：`LayerPanel._refreshLayerList()` 与 `LayerManager.syncLayers()` 之间的事件循环导致 `Maximum call stack size exceeded`
  - 原因：`_refreshLayerList()` → `syncLayers()` → `emit('layers:updated')` → `_refreshLayerList()` 无限递归
  - 修复：在 `_refreshLayerList()` 中加 `_refreshing` 重入锁标志，在进入时检查、退出和早期 return 时释放
- **选择图片后画布不显示**（第三轮修复 — 真正根因）：
  - 查阅 uTools 官方文档发现 `utools.showOpenDialog()` 返回 `string[]`（文件路径数组），代码错误地当成 `{ filePaths: [] }` 对象 → `result.filePaths` 永远 `undefined` → 条件永远 false → `_loadImage` 从未被调用！
  - 修复：`result.filePaths[0]` → `result[0]`；去掉 `await`（API 是同步的）
  - `utools.showSaveDialog()` 同理返回 `string`，ExportModule 中修复 `result.filePath` → `result`
  - 同时附带修复了 0×0 画布、Fabric.js crossOrigin 参数位置、超时保护等问题

## 交互冲突修复（工具模式下误触发图层移动）
- **问题**：用户在马赛克/剪切/文字模式下操作时，点中已有覆盖层导致图层被拖动
- **根因**：`canvas.selection = false` 只禁用框选，不阻止单个对象的 `selectable`/`evented`
- **修复方案**：在 `BaseModule.activate()` 中统一禁用全部对象的 selectable/evented，deactivate() 中恢复
  - `BaseModule.js`：新增 `_setObjectsInteractivity(interactive)` 方法，activate/deactivate 中调用
  - `MosaicModule.js`：移除冗余的 `canvas.selection` 设置；新建马赛克覆盖层显式设 `selectable: false, evented: false`
  - `CropModule.js`：移除冗余的 `canvas.selection` 设置；裁剪框在 activate 后创建，自带正确设置
  - `TextModule.js`：activate 中恢复文字对象的交互性（允许点击编辑），其他对象（如马赛克覆盖层）保持禁用

## 图层编号重复排序修复
- **问题**：每个操作后图层面板中图层编号（图层名）都会重新排序/重新分配
- **根因**：`LayerManager.syncLayers()` 先将 `this._layers = []` 清空，再调用 `_findMeta()` 在空数组中查找已有元数据 → 永远返回 null → 每次都重建元数据，分配新 ID 和名称
- **修复**：先保存 `oldLayers` 引用，在旧列表中按 `fabricObj` 引用匹配已有元数据，再构建 `newLayers` 列表并赋值给 `this._layers`
- 涉及文件：`src/core/LayerManager.js`

## 裁剪框视口定位修复

  - `_createMask()` / `_createCropRect()` / `_updateMask()` 全部改用可视区域坐标
  - 添加 `absolutePositioned: true` 确保遮罩和裁剪框独立定位

## 下拉框无法选择修复 (2026-06-08 23:14)
- **问题**：选项栏中"效果"下拉框（马赛克/模糊）点击打开后瞬间关闭，用户无法选择
- **根因**：`OptionsBar._handleControlEvent()` 对所有事件类型（`input`/`change`/`click`）都做相同处理。用户点击`<select>`时 `click` 事件触发 → `_updateControls()` → `controlsEl.innerHTML` 被替换 → 原始 `<select>` DOM 被销毁 → 下拉框消失
- **修复**：为所有 `<select>` 控件添加 `e.type === 'change'` 条件检查，只在值真正改变时响应：
  - `mosaic-mode`（效果类型）
  - `text-font-family`（字体）
  - `text-font-size`（字号）
- 涉及文件：`src/ui/OptionsBar.js`
